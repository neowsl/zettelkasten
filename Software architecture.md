In [[How to beat a monopoly - Linear Case Study]], Tom Delalande talks about how early architectural design can set one apart from competitors. Linear was able to break into Atlassian/Jira's because the team at Linear spent a year designing a core system so fast that Atlassian, at its massive scale, would not be able to migrate to easily.

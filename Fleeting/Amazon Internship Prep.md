## Technical interview
- Interview is a conversation. Don't stress, it's more to validate OA performance.
- Don't "pretend" like you don't know how to solve a problem; instead, simply mention you've seen it before and ask how to proceed.
- Ask for hints if necessary!
- Make sure solution works by walking through an example.
- If there's time at end, try to optimise.

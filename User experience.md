In [[How to beat a monopoly - Linear Case Study]], Tom Delalande talks about how we need to *talk to people, not data*. Software today has been optimised for user retention rather than user experience, with metrics like A/B testing. Recalling my SEL UX project, perhaps I was wrong to assume that the most useful data was the Likert scale numbers, and the **qualitative feedback** was more important indicator.

Sometimes in UX, we need to *be opinionated* rather than configurable. Developers should understand the problem and provide a solution, rather than passing on the solution to a middle manager.

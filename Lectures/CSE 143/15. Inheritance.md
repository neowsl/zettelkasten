An object A that **inherits** from object B has a relationship of type "is a". E.g. an engineer *is an* employee.

```java
public class TypeA {
	...
}

public class TypeB extends TypeA {
	...
}
```

Java does not support multiple inheritance.

`Object` is the only class in Java that does not extend from another class. All other objects extend from `Object` in some way.

**Superclass**: A class "above" an object in an inheritance hierarchy.
**Subclass**: A class "below" an object in an inheritance hierarchy.

```java
TypeA x = new TypeB(); // legal
TypeB x = new TypeA(); // illegal
```

---

```java
// declared | actual
TypeA x = new TypeB();

x.bOnlyMethod(); // illegal
((TypeB) x).bOnlyMethod(); // legal, but the cast only applies to this line of code
```

Code execution steps:

1. Compiler - may error
	1. If variable, check declared type
	2. If cast, check cast type
2. Runtime (only for a cast) - may error
	- Checks the **type**, not the field - even if the field/method exists, will still Runtime Error if types mismatch
3. Execute the method of the object - behaves like the *original object*, not the casted object

## Polymorphism

A method defined in a superclass *may change* when a subclass inherits it.

`super.method()` is *not* polymorphic - can just write as-is.

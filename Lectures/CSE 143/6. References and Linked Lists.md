## Linked Lists

- Note: Node classes have public fields rather than private fields.

```java
public class ListNode {
	public int data;
	public ListNode next;
	
	public ListNode(int data) {
		this(data, null);
	}
	
	public ListNode(int data, ListNode next) {
		this.data = data;
		this.next = next;
	}
}
```

```java
ListNode list;
list = new ListNode();
```

IMPORTANT: 20-point question on linked lists on the final

- Note: Must set final next to `null`, otherwise uninitialised error.

```java
ListNode tmp = new ListNode(4, list.next);
list.next = tmp;
```

An interesting way to construct linked lists:

```java
ListNode list = new ListNode(1, new ListNode(2, new ListNode(3)));
```

To approach a linked list problem, label the references in the problem and determine how many references need to change. The number of references is likely the minimum lines of code required to solve the problem.

![[6. References and Linked Lists 2025-10-06 12.12.29.excalidraw]]

In the above diagram, there are 6 total references. If we wanted to make `p = [2, 4, 3]` and `q = [9]`, we would need 3 lines of code:

```java
p.next.next = q;
q = q.next;
p.next.next.next = null;
```

Sets are collections of objects called **elements**.

- $a in B {}$: $a$ is an element of $B$
- $a in.not B {}$: $a$ is not an element of $B$

Some common sets:
- $NN$: The set of natural numbers; $NN = {0, 1, 2, ...}$
- $ZZ$: The set of integers; $ZZ = {..., -2, -1, 0, 1, 2, ...}$
- $QQ$: The set of rational numbers; e.g. 1/2, -17, 32/48
- $RR$: The set of real numbers; e.g. 1, 32/48, $pi$, $sqrt(2)$
- $[n]$ is the set ${1, 2, ..., n}$ where $n$ is a natural number
- $emptyset = {}$ is the empty set; the *only* set with no elements

$A$ and $B$ are **equal** if they have the same elements:

$$ A = B := forall x (x in A <-> x in B) $$

$A$ is a **subset** of $B$ if every element of $A$ is also in $B$:

$$ A subset B := forall x (x in A -> x in B) $$

$$ (A = B) equiv (A subset B) and (B subset A) $$

Set builder notation:

$$ S := {x : P(x)} $$

This means "$S$ is the set of all elements that satisfy $P$".

---

Some set operations:

$$ A union B := {x : (x in A) or (x in B)} $$
$$ A inter B := {x : (x in A) and (x in B)} $$
$$ A \\ B := {x : (x in A) and (x in.not B)} $$
$$ A xor B := {x : (x in A) xor (x in.not B)} $$
$$ overline(A) = A^C := {x : (x in U) xor (x in.not A)} $$

---

De Morgan's Laws:

$$ overline(A union B) = overline(A) inter overline(B) $$
$$ overline(A inter B) = overline(A) union overline(B) $$

---

Recall from [[1. Logic|Topic 1]] that if we show $A equiv B$, we have also shown $(A <-> B) equiv T$. Therefore, we can use an equivalence chain in a calculation block to show a biconditional holds.

---

**Meta-Theorem**: Translate any Propositional Logic equivalence into "=" relationship between sets by replacing $union$ with $or$, $inter$ with $and$, and $.^C$ with $not$.

Thus we can first translate to Propositional Logic, use equivalences, and finally translate back to set notation.

## 2026-05-01: Product and Power Sets

Power set:

$$ cal(P)(A) := {B : B subset A} $$

Cartesian product:

$$ A times B := {x : exists a exists b ((a in A) and (b in B) and (x = (a, b)))} $$

Or also written:

$$ A times B := {(a, b) : a in A, b in B} $$

---

More set builder notation:

- `filter`: ${} S := {x in U and P(x)} {}$
- `map`: $T := {f(x) : x in U}$

These can be chained:

$$ V := {f(x) : x in U and P(x)} $$

Domain restriction:

$$ forall x (x in A -> P(x)) $$

> **Russell's Paradox**
> $$ S := {x : x in.not x} $$
> Suppose that $S in S$. Then, by the definition of $S$, $S in.not S$, but that's a contradiction.
> Suppose that $S in.not S$. Then by the definition of $S$, $S in S$, but that's a contradiction too.

### Recursive definitions of sets

Natural numbers:
- Basis: $0 in S$
- Recursive: If $x in S$, then $x + 1 in S$

Even numbers
- Basis: $0 in S$
- Recursive: If $x in S$, then $x + 2 in S$

Powers of 3:
- Basis: $1 in S$
- Recursive: If $x in S$, then ${} 3x in S$

## 2026-05-04: Recursively Defined Sets

How to prove $forall x in S, P(x)$ is true:

- Base Case: Show that $P(u)$ is true for all specific elements $u$ of $S$ mentioned in the *Basis step*.
- Inductive Hypothesis: Assume that $P$ is true for some arbitrary values of *each* of the **existing named elements** mentioned in the *Recursive step*.
- Inductive Step: Prove that $P(w)$ holds for each of the **new elements $w$** constructed in the *Recursive step* using the named elements mentioned in the Inductive Hypothesis
- Conclude that $forall x in S, P(x)$.

### Lists of integers

- Basis: $"nil" in "List"$
- Recursive step:
	- If $L in "List"$ and $a in ZZ$, then $a :: L in "List"$

### Functions on lists

**Length**:
- `len(nil) := 0`
- `len(a :: L) := len(L) + 1`

**Concatenation**:
- `concat(nil, R) := R`
- `concat(a :: L, R) := a :: concat(L, R)`

## 2026-05-06: Structural Induction

### Rooted binary trees

Basis: $dot$ is a rooted binary tree.
Recursive step: If $T_1$ and $T_2$ are rooted binary trees, then $T_1 ^("/"^dot "\\") T_2$ is also a rooted binary tree.

### Functions on rooted binary trees

- $"size"(dot) := 1$
- $"size"("tree") := 1 + "size"(T_1) + "size"(T_2)$
- $"height"(dot) := 0$
- $"height"("tree") := 1 + max("height"(T_1), "height"(T_2))$

### Strings

- An **alphabet** ${} Sigma$ is any finite set of characters.
- $Sigma^*$ is the set of **strings** over the alphabet $Sigma$.
	- Example: ${0, 1}^*$ is the set of binary strings.
		- 0, 1, 00, 01, 10, 11, ... and ""
- $Sigma^*$ is defined recursively by
	- Basis: $epsilon in Sigma^*$ ($epsilon$ is the empty string, i.e., "").
	- Recursive: If $w in Sigma^*$, $a in Sigma$, then $w a in Sigma^*$.

### Functions on strings

Length:
- $"len"(epsilon) := 0$
- $"len"(w a) := "len"(w) + 1$ for $w in Sigma^*, a in Sigma$

Concatenation:
- $x dot epsilon := x$ for $x in Sigma^*$
- $x dot w a := (x dot w)a$ for $x in Sigma^*, a in Sigma$

Reversal:
- $epsilon^R := epsilon$
- ${} (w a)^R := epsilon a dot w^R {}$ for $w in Sigma^*, a in Sigma$

Number of $c$'s in a string:
- $"#"_c (epsilon) := 0$
- $"#"_c (w c) := "#"_c (w) + 1$ for $w in Sigma^*$
- $"#"_c (w a) := "#"_c (w)$ for ${} w in Sigma^*, a in Sigma, a != c {}$

> $$ cal(L) { f(t) } = integral_0^infinity e^(-s t) f(t) d t $$

---

> *Example*
> Find the Laplace transforms of the following functions and give their domains.
> 1. $f(t) = 1$

$cal(L) { f(t) } = integral_0^infinity e^(-s t) dot 1 d t$
$= lim_(N arrow infinity) integral_0^N e^(-s t) d t$
$= lim_(N arrow infinity) e^(-s t) / (-s) |_0^N$
$= lim_(N arrow infinity) (e^(-s N) - 1) / (-s)$
$= 1/s$

$$ cal(L) { f'(t) } (s) = s cal(L) { f(t) } - f(0) $$

When $a$ and $b$ are constant:
$$ cal(L) { a f(t) + b g(t) } = a cal(L) { f(t) } + b cal(L) { g(t) } $$

$$ cal(L) { f''(t) } = s cal(L) { f'(t) } - f'(0) = s(s cal(L) { f(t) } - f(0)) - f'(0) $$
$$ = s^2 cal(L) { f(t) } - f'(0) - s f'(0) $$

$$ laplace(f^((n))(t)) = s^n laplace(f(t)) - f^((n - 1))(0) - s f^((n - 2))(0) - ... - s^(n - 1) f(0) $$

---

> *Example*
> Let $y$ be a solution to the initial value problem
> $$ y'' - 4y = 1, y(0) = 0, y'(0) = 1 $$

1. Take the Laplace transform of the equation:
	$laplace(y'') - 4 laplace(y) = laplace(1)$
2. Apply the formula
	$s^2 laplace(y) - y'(0) - s y(0) - 4 laplace(y) = 1/s$
3. Replace the initial conditions
	$(s^2 - 4) - 1 - 0 = 1/s$
4. Solve for $laplace(y)$
	$laplace(y) = (s + 1) / (s(s^2 - 4))$
5. Use partial fraction decomposition
	$laplace(y) = (-1/4) / s + (3/8) / (s - 2) + (-1/8) / (s + 2)$
6. Reverse the Laplace transform
	$y = -1/4 + 3/8 e^(2t) - 1/8 e^(-2t)$

### Piecewise functions

Let
$$
u_c (t) = cases(
  0 "if" t < c,
  1 "if" t >= c
)
$$

We must split apart our function to handle each individual case ($t < c, t >= c$).

If
$$
g(t) = cases(
  g_1 (t) "if" t < a_1,
  g_2 (t) "if" a_1 <= t < a_2,
  g_3 (t) "if" a_2 <= t < a_3,
  g_4 (t) "if" a_3 <= t < a_4,
  ...
)
$$

Then
$$ g(t) = g_1 (t) + u_(a_1) (t) dot (g_2 (t) - g_1 (t)) + u_(a_2) (t) dot (g_3 (t) - g_2 (t)) + ... $$

---

> *Laplace transform of a piecewise function*
> $$ laplace(f(t - c) dot u_c (t)) = e^(-s c) laplace(f(t)) $$

> *Inverse laplace transform of a piecewise function*
> $$ laplace(h(t) dot u_c (t)) = e^(-s c) laplace(h(t + c)) $$

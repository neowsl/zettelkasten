## 2026-05-11

3 C's of cache misses:
- **Compulsory** (cold) miss: Occurs on first access to a block.
	- To help, increase the block size.
- **Conflict** miss: Occurs when the cache is large enough, but multiple blocks map to the same set.
	- To help, increase the associativity.
- **Capacity** miss: When the set of active cache blocks is larger than the cache.
	- I.e. won't fit even if cache was fully-associative.
	- To help, increase the cache size or decrease the working set of data.

---

What to do on a write-hit?
- **Write-through** (write now): Write immediately to next level.
- **Write-back** (write later): Defer write to next level until line is evicted.
	- Requires a "dirty bit" to track if line is modified.

What to do on a write-miss?
- **Write allocate** (fetch on write): Load into cache, then execute the write-hit policy.
	- Good if more writes or reads to the location follow.
- **No-write allocate** (write around): Immediately write to next level.

Typical caches:
- Write-back + write allocate (more common)
- Write-through + no-write allocate

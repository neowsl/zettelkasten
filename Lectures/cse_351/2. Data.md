## 2026-04-01

An address is just a number represented in fixed-length binary.
Each "box" of memory is a byte (8 bits), usually written in hex form.
Addresses refer to *bytes*, not individual *bits*. I.e. address 4 = the 32nd bit.

Historically, all instructions were exactly the size of a **word**.
Now, **word size** = address size = register size.
Current x86 systems use 64-bit (8-byte) words.

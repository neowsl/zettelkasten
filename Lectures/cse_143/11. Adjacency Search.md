**Fencepost problem**: Where you need $N - 1$ things between $N$ things.

To turn any object into a string in Java:

```java
"" + obj;
```

```java
public static void showMatches(Map<String, Set<String>> friends, String name1, String name2) {
	Set<String> currentGroup = new TreeSet<>();
	Set<String> alreadySeen = new TreeSet<>();
	currentGroup.add(name1);
	
	int distance = 0;
	while (!currentGroup.contains(name2) && !currentGroup.isEmpty()) {
		distance++;
		alreadySeen.addAll(currentGroup);
		
		Set<String> nextGroup = new TreeSet<>();
		for (String friend : currentGroup) {
			nextGroup.addAll(friends.get(friend));
		}
		
		nextGroup.removeAll(alreadySeen);
		currentGroup = nextGroup;
	}
	
	if (currentGroup.contains(name2)) {
		System.out.println(distance);
	} else {
		System.out.println("not found");
	}
}
```

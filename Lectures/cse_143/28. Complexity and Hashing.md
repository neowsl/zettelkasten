| Structure            | add      | find     | remove   |
| -------------------- | -------- | -------- | -------- |
| Unsorted array       | O(1)     | O(n)     | O(n)     |
| Sorted array         | O(n)     | O(log n) | O(n)     |
| Unsorted linked list | O(1)     | O(n)     | O(n)     |
| Sorted linked list   | O(n)     | O(n)     | O(n)     |
| Binary search tree   | O(log n) | O(log n) | O(log n) |
| Hash table           | O(1)     | O(1)     | O(1)     | 

See also: [Skip list](https://en.wikipedia.org/wiki/Skip_list)

Note that a binary search tree can't be used for non-comparable objects. Remember on final!!! TreeSet vs. HashSet, TreeMap vs. HashMap!!!

Hashing requires:
- Hash function (data -> int)
- Roomy array

**Separate chaining**: Use a linked list per hash code to store potentially multiple elements

$lambda$: Load factor (how much of the array is used up as a ratio)

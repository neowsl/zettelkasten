Every recursive solution will have at least one recursive case and one base case.

```java
public void writeStars(int n) {
	if (n == 0) {
		System.out.println();
	} else {
		System.out.print("*");
		writeStars(n - 1);
	}
}
```

```java
public void reverse(Scanner input) {
	if (input.hasNextLine()) {
		String line = input.nextLine();
		reverse(input);
		System.out.println(line);
	}
}
```

```java
public int stutter(int n) {
	if (n < 0) {
		return -stutter(-n);
	} else if (n < 10) {
		return n * 11;
	} else {
		return 100 * stutter(n / 10) + stutter(n % 10);
	}
}
```

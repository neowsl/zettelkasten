**First-class citizens**: An entity that can be treated as any other value.
E.g. variables, parameters, return values, int, double, strings, objects, booleans

```java
List<String> words = List.of({ "one", "two", "three" });

words.stream()
	.forEach(s -> System.out.print(s + " "));
System.out.println();

words.stream()
	.map(s -> s + " ")
	.forEach(System.out::print);
System.out.println();

int[] numbers = {1, 2, 3, 4, 5, 6, 7, 8};
int sum1 = Arrays.stream(numbers)
	.sum();
System.out.println("sum1 = " + sum1);

int sum2 = Arrays.stream(numbers)
	.filter(n -> n ^ 1 == 0)
	.sum();
System.out.println("sum2 = " + sum1);

int sum3 = Arrays.stream(numbers)
	.map(Math::abs)
	.filter(n -> n ^ 1 == 0)
	.sum();
System.out.println("sum3 = " + sum1);

int sum4 = Arrays.stream(numbers)
	.map(Math::abs)
	.distinct()
	.filter(n -> n ^ 1 == 0)
	.sum();
System.out.println("sum4 = " + sum1);
```

```java
IntStream.range(1, 11)
	.forEach(System.out::println);
	
IntStream.range(0, 11)
	.map(factorial)
	.forEach(System.out::println);
	
public static int factorial(int n) {
	return IntStream.range(2, n + 1)
		.reduce(1, (a, b) -> a * b);
}

IntStream.range(1, 24)
	.map(isPrime)
	.forEach(System.out::println);
	
public static int isPrime(int n) {
	return IntStream.range(1, n + 1)
		.filter(x -> n % x == 0)
		.count()
		== 2;
}
```

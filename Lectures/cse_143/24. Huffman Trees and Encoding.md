**ASCII**: American Standard Code for Information Interchange

Codes in a Huffman encoding have the **prefix property** (i.e. no code is a prefix of another code). This is because each code is a leaf node of the tree, and no code has children.

Encoding process:
1. Create a node for each character with a frequency of that character.
2. Insert all nodes into a priority queue, ranked by frequency ascending.
3. While the queue has more than 1 element, join the first 2 elements with a parent node.
4. Once the tree is constructed, traverse down the edges (0 for left, 1 for right) to determine the code for each character.

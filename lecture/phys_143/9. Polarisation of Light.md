## 2026-05-29

2 sets of polarising filters:
- **Blue**: Up-down or left-right
- **Green**: Diagonal

If I only make measurements with a set of blue filters, then I know exactly which photons make it through each filter. Same with a set of green filters.

However, if I use a combination of blue and green filters, knowing which light made it through one does not give me any information about what light makes it through the other.

## 2026-06-03

We can split a high-energy photon by passing it through a crystal. The split photons are now **entangled**. Two observers can each *randomly* choose a polarising filter, and the entangled photons will behave the same.

- Twin knows what happens *instantly*

### Quantum cryptography

Point of cryptography is not to prevent a message from being *intercepted*, it's to prevent a message from being *read* (because someone has to intercept the message at some point).

As long as key is longer than the message, theoretically unbreakable.

So now the problem is making sure the *key* doesn't get copied in transit...

Key sending protocol:
- Send twinned photons
- Randomly choose set (blue vs. green frames)
- Later publicly say which frame you used for each photon (but not what you saw)
- Only keep photons where same frames were used

Now, even if the very bad man cut the fibre, he has to decide which frame to use for each observation. He must make a guess, and that guess is wrong half the time. Thus, we can deduce if the key was intercepted.

## 2026-01-26

1st order linear: $y' + p(x) y = g(x)$
2nd order linear: $y'' + p(x) y' + q(x) y = g(x)$
nth order linear: $a(x) y^((n)) + b(x) y^((n - 1)) + ... = g(x)$

A linear DE is **homogeneous** if $g(x) = 0$.
A linear DE has **constant coefficients** if $p(x), g(x)$ are constant.

Two functions $y_1(t)$, $y_2(t)$ are called
- **linearly independent** if neither one is a constant multiple of the other
- **linearly dependent** if one is a constant multiple of the other

For a second-order linear homogeneous DE, any two linearly independent solutions ${y_1(t), y_2(t)}$ form a **fundamental set of solutions** of the DE. This is because a second-order linear homogeneous DE requires 2 initial conditions!

For an $n$-th order linear homogeneous DE, any $n$ linearly independent solutions form a fundamental set of solutions.

### Superposition

For any linear DE, if $y_1(x)$ and $y_2(x)$ are solutions, $==> c_1 y_1(x) + c_2 y_2(x)$ is also a solution.

For any number of solutions, any *linear combination* of the solutions is also a solution. (Recall the solution space in linear algebra)

This is known as the **principle of superposition**.

### Characteristic equations

The **characteristic equation** describes exponential solutions to a DE.

For the DE $y'' - 7y' + 12y = 0$, the characteristic equation is $r^2 - 7r + 12 = 0$. Since $r = {3, 4}$ satisfies the characteristic equation, $y(x) = C_1 e^(3x) + C_2 e^(4x)$ are solutions to the DE.

This also applies to imaginary solutions! I.e. $y(x) = C_1 e^((-2 + 3i)x) + C_2 e^((-2 - 3i)x)$

### Complex numbers

$$ e^(i theta) = cos theta + i sin theta $$

We can represent coordinates with $z = r e^(i theta)$.

Conjugates: If $z = a + i b$, $overline(z) = a - i b$. $z dot overline(z) = a^2 + b^2$.

You can multiply a complex fraction by the conjugate of its denominator to obtain a nicer form.

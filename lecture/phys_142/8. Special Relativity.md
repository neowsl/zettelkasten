## 2026-02-27

Special relativity is *all about measurement*.

To be precise, we need a **reference frame**. I.e., look at the clock at the location where something occurs. We can measure the time $t$ and the location $x$ of an **event**.

Every reference frame has its own set of clocks an **intelligent observer** can draw conclusions based on observations.

## 2026-03-02

All observers in the same reference frame (i.e. having no relative motion with each other) will agree on **all** conclusions.

The velocity of a reference frame is its defining trait.

---

Speed of light $c = 3 times 10^8 "m/s"$ in **all** reference frames.

Nothing travels faster than light.

## 2026-03-04

Causality: If Event A causes Event B, then A must come before B in *any* timeline.

$$ gamma = 1 / sqrt(1 - beta^2) $$

Where $beta$ is a fraction of $c$ (the speed of light).

---

**Coordinate time**: Two synchronised clocks at rest wrt each other.
**Proper time**: A single clock at two events / wristwatch time (reading the time using the same wristwatch).

**Spacetime interval**: Measured by a single clock present for both events, following an *inertial path*.
$$ (Delta s)^2 = (Delta t)^2 - (Delta x)^2 $$

Metric equation:
$$ (Delta t_R)^2 - (Delta x_R)^2 = (Delta t_B)^2 - (Delta x_B)^2 $$

I.e., if we know this quantity in one reference frame, we can deduce it for another reference frame.

**Light clock**: Light is produced from a source, bounces off a mirror, and returns to the source (where the time elapsed is measured).

## 2026-03-06

If two events happen at the same location and at the same time in one reference frame, they happen simultaneously at *all* reference frames.

If two events happen at the same location in some order in one reference frame, they happen in that same order in *all* reference frames.

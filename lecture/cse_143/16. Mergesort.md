```java
public static void sort(Queue<String> list) {
	if (list.size() > 1) {
		int size1 = list.size() / 2;
		int size2 = list.size() - size1; // easy way to ensure they add up!
		Queue<String> half1 = new LinkedList<>();
		Queue<String> half2 = new LinkedList<>();
		for (int i = 0; i < size1; i++) {
			half1.add(list.remove());
		}
		for (int i = 0; i < size2; i++) {
			half1.add(list.remove());
		}
		
		sort(half1);
		sort(half2);
		
		mergeInto(list, half1, half2);
	}
}

// pre: list1 and list2 are in sorted order
// post: values are moved from list1 and list2 into result so as to preserve sorted order
public static void mergeInto(Queue<String> result, Queue<String> list1, Queue<String> list2) {
	while (!list1.isEmpty() && !list2.isEmpty()) {
		if (list1.peek().compareTo(list2.peek()) <= 0) {
			result.add(list1.remove());
		} else {
			result.add(list2.remove());
		}
	}
	
	while (!list1.isEmpty()) {
		result.add(list1.remove());
	}
	while (!list2.isEmpty()) {
		result.add(list2.remove());
	}
}
```

- `compareTo()` returns < 0 if less than, > 0 if greater than. Simple mnemonic to remember: < 0 for less, > 0 for greater.

**Stable sort**: Preserves the relative order of keys.

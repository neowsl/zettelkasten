Similar to nested for-loops.

```java
// pre: queens have been placed in columns less than col so that no two threaten each other
// post: explore all possible placements of queens starting in column col
private static void explore(Board b, int col) {
	if (col > b.size()) {
		b.print(); // hooray!
	} else {
		for (int row = 1; row <= b.size(); row++) {
			if (b.safe(row, col)) {
				b.place(row, col);
				explore(b, col + 1);
				b.remove(row, col);
			}
		}
	}
}
```

Backtracking mantra: *Choose, explore, unchoose*

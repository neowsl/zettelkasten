Note: The "minus other" trick only works for integers.

If something can be done with an interface, it should be done with an interface (multiple interfaces can be implemented).

```java
public abstract class Shape implements Comparable<Shape> {
	private String name;
	
	public Shape(String name) {
		this.name = name;
	}
	
	public abstract double area();
	
	public final int compareTo(Shape other) {
		double difference = area() - other.area();
		if (difference < 0) return -1;
		if (difference == 0) return 0;
		return 1;
	}
	
	public final String toString() {
		return name + " of area " + area();
	}
}
```

```java
public class Rectangle implements Shape {
	private double length;
	private double width;
	
	public Rectangle(double length, double width) {
		super("rectangle");
		this.length = length;
		this.width = width;
	}
	
	public double area() {
		return length * width;
	}
}
```

```java
public class Square implements Shape {
	private double length;
	
	public Square(double length) {
		super("square");

	}
	
	public double area() {
		return length * length;
```

**Concrete class**: All filled in
**Interface**: All hollow

We want "some of each". This is an **abstract class**.

Every constructor that doesn't begin with `this()` must begin with `super()`.

A good inheritance hierarchy allows for *additive, not invasive, change*.

Methods can be `final`, meaning subclasses cannot alter the method.
Classes cannot be `final`, meaning no subclasses can even be made.

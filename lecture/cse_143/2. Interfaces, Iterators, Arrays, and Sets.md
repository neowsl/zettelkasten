## Interfaces

```java
class MyClass implements OtherClass {...}
```

Always use the more general version of a class when declaring a variable:
```java
// BAD
MyClass x = new MyClass();
// GOOD
OtherClass x = new MyClass();
```

## Iterators

- `hasNext()`: Is there more data?
- `next()`: Returns the next value, moves forward
- `remove()`: Removes the value most recently returned by `next()`

```java
Iterator<String> itr = list.iterator();
while (itr.hasNext()) {
	String next = itr.next();
	System.out.println(next);
}
```

## Arrays

Initialise with:
```java
int[] data = {1, 2, 3, 4, 5};
```

- Note: Generic structures cannot store primitives (e.g. `int`).
	- Instead, use **wrapper classes** such as `Integer`.

```java
List<Integer> nums1 = new ArrayList<>();
```

## Sets

Similar to a list, but
1. All elements are unique
2. Order is not controlled by client

```java
Set<Integer> nums2 = new TreeSet<>();
```

- Note: `TreeSet` sorts values in ascending order.

> Iterators are good for mutations on Sets.

```java
Iterator<Integer> itr = nums2.iterator();
while (itr.hasNext()) {
	int n = itr.next();
	if (n % 3 == 0) {
		itr.remove();
	}
}
```

- Note: `ConcurrentModificationException`: Do not remove from a parent Collection while using an Iterator.
	- `modCount` is used to manage this.

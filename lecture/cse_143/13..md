**Public-private pair**: A public method with a private helper method for recursion (allows for extra parameters that you decide!)

```java
public static void print(File f, int indent) {
	for (int i = 0; i < indent; i++) {
		System.out.println("    ");
	}
	System.out.println(f.getName());
	if (f.isDirectory()) {
		for (File subF : f.listFiles()) {
			print(subF, indent + 1);
		}
	}
}
```

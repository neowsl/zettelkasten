"The" complexity generally means time complexity.

Linear search: $O(n)$

Find the most frequently executed line of code; that is the big-O.

## Complexity classes

- $O(1)$: Linked list insertion
- $O(log n)$: Binary search
- $O(n)$: Complete search
- $O(n log n)$: Quicksort
- $O(n^2)$: Bubble sort
- $O(n^3)$
- $O(2^n)$

Pilot with the jelly doughnut: Don't overoptimise small tasks, unless it makes an algorithm go from one complexity class to another.

> A **proposition** is a well-formed sentence.

- Can be true or false

We need a way of talking about *arbitrary* ideas:
I.e. we need "atoms" of a language

Propositional variables: $p$, $q$, $r$, $s$
Constant truth values:
$T$ for true
$F$ for false

| Term             | Syntax    | Associativity |
| ---------------- | --------- | ------------- |
| Negation (not)   | $not p$   |               |
| Conjuction (and) | $p and q$ | Left-to-right |
| Disjunction (or) | $p or q$  | ^             |
| Exclusive Or     | $p xor q$ | ^             |
| Implication      | $p -> r$  | Right-to-left |
| Biconditional    | $p <-> q$ | ^             | 

(Higher on the table = higher precedence)

$p or q or v or t$ means $(((p or q) or v) or t)$
$p -> q -> r$ means $p -> (q -> r)$

---

## Implication: $p -> r$

| $p$ | $r$ | $p -> r$ |
| --- | --- | -------- |
| T   | T   | T        |
| T   | F   | F        |
| F   | T   | T        |
| F   | F   | T        |

With implication ($->$) , $p$ is called the **premise** and $r$ is called the **conclusion**.
The implication is true when $p$ and $r$ are true.
The implication is true ("vacuously") when $p$ is false.

In English, "if x, then y" is equivalent to "y if x".
"if x, then y" is also equivalent to "x only if y".

## Biconditional: $p <-> r$

| $p$ | $r$ | $p <-> r$ |
| --- | --- | --------- |
| T   | T   | T         |
| T   | F   | F         |
| F   | T   | F         |
| F   | F   | T         |

---

Steps to analyse an English sentence:
1. Assign a variable to each "atom" of the sentence
2. Translate connectives
3. Create a truth table
4. Add additional columns for intermediate logic (for compound statements)

## 2026-04-02: Propositional Logic

> A **proposition** is a well-formed sentence.

- Can be true or false

We need a way of talking about *arbitrary* ideas:
I.e. we need "atoms" of a language

Propositional variables: $p$, $q$, $r$, $s$
Constant truth values:
$T$ for true
$F$ for false

| Term             | Syntax    | Associativity |
| ---------------- | --------- | ------------- |
| Negation (not)   | $not p$   |               |
| Conjuction (and) | $p and q$ | Left-to-right |
| Disjunction (or) | $p or q$  | ^             |
| Exclusive Or     | $p xor q$ | ^             |
| Implication      | $p -> r$  | Right-to-left |
| Biconditional    | $p <-> q$ | ^             | 

(Higher on the table = higher precedence)

$p or q or v or t$ means $(((p or q) or v) or t)$
$p -> q -> r$ means $p -> (q -> r)$

---

### Implication: $p -> r$

| $p$ | $r$ | $p -> r$ |
| --- | --- | -------- |
| T   | T   | T        |
| T   | F   | F        |
| F   | T   | T        |
| F   | F   | T        |

With implication ($->$) , $p$ is called the **premise** and $r$ is called the **conclusion**.
The implication is true when $p$ and $r$ are true.
The implication is true ("vacuously") when $p$ is false.

In English, "if x, then y" is equivalent to "y if x".
"if x, then y" is also equivalent to "x only if y".

### Biconditional: $p <-> r$

| $p$ | $r$ | $p <-> r$ |
| --- | --- | --------- |
| T   | T   | T         |
| T   | F   | F         |
| F   | T   | F         |
| F   | F   | T         |

---

Steps to analyse an English sentence:
1. Assign a variable to each "atom" of the sentence
2. Translate connectives
3. Create a truth table
4. Add additional columns for intermediate logic (for compound statements)

## 2026-04-01: Circuits

Implication: $p -> r$
Contrapositive: $not r -> not p$
Converse: $r -> p$
Inverse: $not p -> not r$

Propositional logic statements with the same truth tables are considered **equivalent**.

**Canonical CNF form**: Exactly *one* representation of an expression (if they don't look the same, they aren't the same). Same applies for **canonical DNF form**.

### Canonical DNF

A.k.a. "sum of products"

1. Find all T rows in the truth table
2. For each T row, write an expression that is T in that row but no others (a **min term**)
3. Form the disjunction (OR) of the min terms

### Canonical CNF

A.k.a. "product of sums"

1. Find all F rows in the truth table
2. For each F row, write an expression that is T in every row *but* that one (a **max term**)
3. Form the conjunction (AND) of the max terms

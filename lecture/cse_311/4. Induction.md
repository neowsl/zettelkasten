## 2026-04-24: Induction

Every operation that we've discussed so far is **reversible**.

Many classes teach doing proofs backward: Going from $15x + 5 = 5(-3x - 1)$ to $0 = 0$. This is proof of nothing: $P -> T$ is a tautology. This only works oftentimes because our operations are reversible. If we truly wanted to prove it, we need to start from $0 = 0$.

---

> *Example*
> Prove $forall k ((a equiv_m b) -> (a^k equiv_m b^k))$.

Let $k$ be an arbitrary *non-negative* integer.
Suppose that $a equiv_m b$.
We know $((a equiv_m b) and (a equiv_m b) -> (a^2 equiv_m b^2))$ by multiplying congruences. So, by applying this repeatedly, we have:
$$ ((a equiv_m b) and (a equiv_m b) -> (a^2 equiv_m b^2)) $$
$$ ((a^2 equiv_m b^2) and (a equiv_m b) -> (a^3 equiv_m b^3)) $$
$$ ... $$
$$ ((a^(k - 1) equiv_m b^(k - 1)) and (a equiv_m b) -> (a^k equiv_m b^k)) $$

- Induction
$$
upright(forall k (P(k) -> P(k + 1))) \
#line(length: 4em, stroke: 2pt + white) \
therefore upright(forall n P(n))
$$

All inductive steps must use the inductive hypothesis!

## 2026-04-27: Strong Induction

- Strong induction
$$
upright(forall k (forall j ((0 <= j <= k) -> P(j)) -> P(k + 1))) \
#line(length: 4em, stroke: 2pt + white) \
therefore upright(forall n P(n))
$$

For strong induction, we can have multiple base cases.

## 2026-04-08: Proofs for Propositional Logic

Equivalences: $A equiv B$ and $(A <-> B) equiv T$ are the same.
Inference: $A => B$ and $(A -> B) equiv T$ are the same.

---

**Modus Ponens**: If $A$ and $A -> B$ are both true, then $B$ must be true.

$$
upright(A \; A -> B) \
#line(length: 4em, stroke: 2pt + white) \
therefore upright(B)
$$

> *Example*
> Show that $r$ follows from $p$, $p -> q$, and $q -> r$.

1. $p$ Given
2. $p -> q$ Given
3. $q -> r$ Given
4. $q$ MP: 1, 2
5. $r$ MP: 4, 3

**Axioms**: Inferring stuff from "nothing".

$$
#line(length: 4em, stroke: 2pt + white) \
therefore upright(C \, D)
$$

E.g.
$$
#line(length: 4em, stroke: 2pt + white) \
therefore A or not A
$$

### Simple propositional inference rules

- Elim $and$
$$
upright(A and B) \
#line(length: 4em, stroke: 2pt + white) \
therefore upright(A \, B)
$$
- Elim $or$:
$$
upright(A or B \; not A) \
#line(length: 4em, stroke: 2pt + white) \
therefore upright(B)
$$
- Modus Ponens:
$$
upright(A \; A -> B) \
#line(length: 4em, stroke: 2pt + white) \
therefore upright(B)
$$
- Intro $and$
$$
upright(A \; B) \
#line(length: 4em, stroke: 2pt + white) \
therefore upright(A and B)
$$
- Intro $or$
$$
upright(A) \
#line(length: 4em, stroke: 2pt + white) \
therefore upright(A or B \, B or A)
$$
- Direct Proof
$$
upright(A => B) \
#line(length: 4em, stroke: 2pt + white) \
therefore upright(A -> B)
$$
Here, we *assume* $A$ is true in a subproof, where we need to prove that $B$ is true. Only then can we assert $A -> B$.

### General proof strategy

1. Use introduction rules to see how to build up to what is necessary.
2. Use elimination rules to break down the given formulas to get the pieces necessary for 1.
3. Write the proof beginning with 2, followed by 1.

## 2026-04-10: Proofs for Predicate Logic

| Rule     | Elimination                | Introduction         |
| -------- | -------------------------- | -------------------- |
| $and$    | Elim $and$                 | Intro $and$          |
| $or$     | Cases                      | Intro $or$           |
| $->$     | Modus Ponens               | Direct Proof         |
| $not$    | Principium Contradictionis | Reductio Ad Absurdum |
| F/T      | Ex Falso Quodlibet         | Ad Litteram Verum    |
| $exists$ |                            | Intro $exists$       |
| $forall$ | Elim $forall$              |                      |

- Cases
$$
upright(A or B \; A -> C \; B -> C) \
#line(length: 4em, stroke: 2pt + white) \
therefore upright(C)
$$
- Principium Contradictionis
$$
upright(A \; not A) \
#line(length: 4em, stroke: 2pt + white) \
therefore upright(F)
$$
- Reductio Ad Absurdum
$$
upright(B => F) \
#line(length: 4em, stroke: 2pt + white) \
therefore upright(not B)
$$
- Ex Falso Quodlibet
$$
upright(F) \
#line(length: 4em, stroke: 2pt + white) \
therefore upright(A)
$$
- Ad Litteram Verum
$$
upright("") \
#line(length: 4em, stroke: 2pt + white) \
therefore upright(T)
$$
- Intro $exists$
$$
upright(P(c) "for some" c) \
#line(length: 4em, stroke: 2pt + white) \
therefore upright(exists P(c))
$$
- Elim $forall$
$$
upright(forall x P(x)) \
#line(length: 4em, stroke: 2pt + white) \
therefore upright(P(a) "for any" a)
$$

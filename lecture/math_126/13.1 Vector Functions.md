> **Vector function**
> A **vector function** is a function which takes a real number input $t$ and outputs a vector $arrow(r)(t) = angle.l f(t), g(t), h(t) angle.r$.

> **Space curve**
> The **space curve** of a vector function is the curve traced out by the tip of the vector function.

> The **limit** of a vector function is:
> $$ lim_(t arrow a) arrow(r)(t) = angle.l lim_(t arrow a) f(t), lim_(t arrow a) f(t), lim_(t arrow a) f(t) angle.r $$

## How to paramatrise intersections

To paramatrise a space curve:
1. Set one variable ($x$, $y$, or $z$ equal to $t$.
	- Careful: Need to solve for other variables in terms of $t$. E.g. $x^2 + y^2 = 1$ won't work, since we will end up with $y = plus.minus sqrt(1 - t^2)$ ($y$ is not a function anymore).
2. If circles or ellipses are present, use sine or cosine.
	- E.g. $x = cos t$, $y = sin t$ -> $arrow(r)(t) = angle.l cos t, sin t angle.r$.

> *Example*
> Find a vector function $arrow(r)(t)$ that represents the curve of intersection of the cone $z = sqrt(x^2 + y^2)$ and the plane $z = 3 - y$.

$sqrt(x^2 + y^2) = 3 + y$
$x^2 + y^2 = 9 + 6y + y^2$
$x^2 = 9 + 6y$

Set $x = t$:
$t^2 = 9 + 6y$
$y = (t^2 - 9) / 6$

Solve for $z$:
$z = 3 + y$
$z = 3 + (t^2 - 9) / 6$

$$ arrow(r)(t) = angle.l t, (t^2 - 9) / 6, 3 + (t^2 - 9) / 6 angle.r $$

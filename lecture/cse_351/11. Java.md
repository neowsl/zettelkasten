## 2026-06-01

Data in Java:
- Pointers are called references in Java
- Java's portability-guarantee fixes the sizes of all types (e.g. `int` will always be 4 bytes, regardless of machine)
- No unsigned types to avoid conversion pitfalls.
- `null` is typically represented as 0 but "you can't tell"

Arrays in Java:
- Every element initialised to 0 or `null`
- Length specified in immutable field at start of array (accessed via `array.length`)
- Every access triggers a bounds-check

Strings in Java
- Two-byte Unicode instead of ASCII
- String not bounded by a `\0` (instead stored as hidden length field)
- All String objects read-only

Classes in Java
- Similar to structs in C
- References mean less spatial locality

References in C
- References in Java can only point to *the starts of* objects

## 2026-05-15

### Allocating a block

For `malloc(n)`:
- Payload size: `n`
- Metadata: Size of the header `h`
- Padding: Add to `n + h` to reach the nearest multiple of alignment

**Minimum block size**: Smallest possible block that we can allocate.
- Think about what size is allocated by `malloc(1)`

If selected block is larger than necessary, we need to **split** the block to allow for more data to be stored.

### Deallocating a block

Each block has a header and a footer with a `size` and a bit `a` (whether or not it's allocated).

Bidirectional coalescing: Only 4 possible scenarios for what happens after block is free; simply combine into larger blocks.

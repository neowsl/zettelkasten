## 2026-04-15

### Memory addressing modes

- General memory operand: `D(Rb, Ri, S)`
	- `D`: Constant displacement value (like an immediate, but no "$")
	- `Rb`: Base register (any register)
	- `Ri`: Index register (any register except `%rsp`)
	- `S`: Scale factor on `Ri` - 1, 2, 4, or 8 for fixed widths of data
- Computed address is `Reg[Rb] + Reg[Ri] * S + D`.
	- Usually dereferenced by instruction: `Mem[Reg[Rb] + Reg[Ri] * S + D]`
		- Example: `moveb 8(%rax,%rbx,2), %cl` will copy the byte of data stored *in memory* at address `Reg[rax] + Reg[rbx] * 2 + 8` into the lowest byte of register `%rcx`.
	- Usefull to encompass data structure memory accesses.
		- Example: `arr[i] <-> *(arr + i) <-> Mem[arr + i * sizeof(data type)]`

### Load effective address

`leaq src, dst`
- `src` is a Mem operand, `dst` is a Reg operand.
	- `lea D(Rb,Ri,S), R`
- Sets `dst` to the *address* computed by the `src` expression.
	- Does not go into memory! - **IT JUST DOES MATH**
